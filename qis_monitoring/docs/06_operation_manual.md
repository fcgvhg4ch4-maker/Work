# 操作マニュアル

対象：毎週月曜日にブックを更新し、社内の地銀担当営業へメールを準備する担当者。

## 0. 初回セットアップ（1 回のみ）

1. `dist/QIS_Fund_Monitoring_Workbook.xlsx` を社内の所定フォルダにコピー。
2. VBA：Alt+F11 → ファイルのインポート → `vba/modQIS.bas` → `.xlsm` で保存。00_Control にボタンを置く場合はマクロを割り当て。
3. Power Query：docs/03 の手順でクエリを作成し、`qPositionLatest` を `05_Position_Raw!A5` に読み込む。
4. `00_Control` の `tblPQParams` にフォルダパスを入力。
5. マスタを実データに置き換え：`02`（ファンド・指数・Mapping）、`03`（地銀・担当者）、`04`（保有）、`08`（NAV 履歴・分配金）、`19`（閾値・休日・イベント）。
   サンプル行は削除する（架空データ）。
6. Bloomberg 接続端末では `19_Settings` の `DataMode` を `BLOOMBERG` にし、`07` の Ticker・Field を確認。
7. `00_Control` の評価基準日・作成日の「手入力」欄を空にする（自動に戻す）。

## 1. 毎週の手順（00_Control D 表と同じ）

| # | 作業 | 操作 | 確認ポイント |
|---|---|---|---|
| 1 | 最新ポジションファイルを保存 | `PositionFolder` へ保存 | ファイル名 `positions_YYYYMMDD.csv` |
| 2 | Excel を開く | 編集を有効化・マクロを有効化 | 評価基準日が前週金曜か |
| 3 | データ更新 | `QIS_RefreshAll`（またはデータ＞すべて更新） | `qPositionImportLog` に ERROR/WARNING がないか |
| 4 | 履歴保存 | `QIS_ArchivePositions` | 追記行数・スキップ・衝突メッセージ |
| 5 | Bloomberg 更新 | `QIS_RefreshBloomberg`（または Bloomberg リボン） | 07 の Status 列（MISSING/STALE） |
| 6 | NAV 照合 | 公式 NAV を 08 に追記 → 自動判定 | 08 C 表の照合結果 |
| 7 | データ品質 | 18 を確認 | Critical の OPEN を解消または Ack（確認者・理由を記入） |
| 8 | 分析更新 | 自動（09〜13） | 13 A 表のアラート。Review Log に確認状況 |
| 9 | 営業優先順位 | 14 | 必要なら Override（理由を備考へ） |
| 10 | コメント | 15 | Auto を確認、修正は Override 列 |
| 11 | メール生成 | 16 で担当者を選択 | ステータス「レビュー可」か、本文 |
| 12 | 下書き作成・記録 | `QIS_CreateOutlookDrafts`（全担当者）または `QIS_CopyEmailBody` → `QIS_LogEmail` | Outlook の下書きフォルダ（**自動送信しない**） |

Bloomberg 未接続の週：`DataMode=MANUAL` のまま、07 の K〜N 列（手入力 評価基準日・前週・前月末・As-of）に値を入力するか、
`qMarketCsv` の結果を貼り付ける。As-of が評価基準日でない値は自動で STALE となり使われない。

## 2. 画面の見方

- **01_Dashboard**：上段に更新状況（評価基準日・データ品質・アラート件数・メール状態）。投資家・営業担当・戦略で絞込可。
  チャート対象ファンドを選ぶと NAV（TRI）と参照指数の 26 週推移（起点 100）を表示。
- **入力セル**：薄黄色＋青字。それ以外は数式（上書きしない）。
- **赤**：リスクアラート（High）・MISMATCH・要確認のみ。

## 3. よくある対応

| 症状 | 原因と対応 |
|---|---|
| メールが「要確認」 | 18 で Critical の OPEN を確認。データを修正するか、確認のうえ Ack（Y・確認者・理由） |
| 週次リターンが空欄 | 評価基準日の公式 NAV 未取得（DQ01）。前週値で代用しない設計。NAV 受領後に再計算 |
| 参照指数前週比が「データ欠損」 | 07 の QIS 指数が MISSING/STALE。値を取得・入力 |
| Index 未登録 | ポジションファイルの Index Name が 02 B 表と不一致。B 表に追加（表記を完全一致） |
| Put/Call が UNKNOWN | Ticker・Name から判定不能。運用会社に確認し、必要なら 05 の Name を補正して再取込 |
| 同一基準日の別ファイル（衝突） | `QIS_ArchivePositions` が追記を止める。どちらが正か確認し、誤った方を 06 から削除して再実行 |
| 新しいファンド・地銀 | 02・03・04 の空行に追加（数式は容量分あらかじめ入っている） |

## 4. 監査・再現

- 06（ポジション）・08（NAV）・07 時系列は**値で**保存。17 にメールの件名・本文・DQ 状態・基準日を保存。
- 過去週を再現するときは 00_Control の評価基準日・作成日を手入力し、`DataMode=MANUAL` で当時の市場値を 07 に入力。
- 閾値変更は 19 で行い、変更日・理由を別途記録（変更履歴はブック外の管理台帳を推奨）。

## 5. 禁止事項

- Bloomberg 由来データの顧客向け転送・再配布（契約条件に従う）。
- 顧客情報（地銀名・保有残高等）の未承認外部サービスへの送信。
- 欠損値の前回値による代用・数式セルの上書き。
- メールの自動送信。
