### 1-3. 母集団確定ルール

1. **識別キー**：`金融機関コード（4桁）` を主キー、`法人番号（13桁）`・`正式名称` を副キー。持株会社は別テーブルで `持株会社法人番号` を傘下銀行にひも付けるのみとし、**分析単位は銀行・金庫単体**（持株会社と傘下銀行の重複計上をしない）。
2. **同一持株会社傘下の複数行**（例：複数行を傘下に持つグループ）は銀行ごとに1行。ただしグループ単位の運用方針（グループ一体運用・市場部門統合）が開示されている場合は `グループ運用フラグ` を立て、営業上はグループ単位でも閲覧可能にする。
3. **再編の取り扱い**：基準日までに合併・商号変更が効力発生したものは存続行のみを母集団とし、`再編履歴` 列に旧行名・効力発生日を記録。過年度比較では合算前の数値を **CONFLICT ではなく「再編による非連続」フラグ**で区別。
   * 基準日後に効力発生予定の統合・合併（例：報道されている名古屋銀行のシズオカFG傘下入り予定、いよぎんHD・愛媛銀行の統合協議 等）は `再編予定` 列に記録し、母集団には現存行として残す。各案件の日付・形態は Phase 1 で一次資料（適時開示）により確認。
4. **信金中央金庫と個別信用金庫は別の投資主体**。信金中金は業態内ランキングの対象外とし、単独プロファイルで分析。
5. 業態変更（例：第二地銀協からの脱退・地銀協への移籍）は協会名簿の基準日時点所属で判定し、移籍履歴を記録。

設計上の留意点（データ定義）

* **外国証券 ≠ 外国債券 ≠ 米国債**。ディスクロ誌の「外国証券」には外国株式・外国投信・外国債券が含まれうるため、列を分け、`外国債券（確認できた場合のみ）` と `米国債（明示開示のみ）` は別列。推計する場合は `ESTIMATED` と計算式を明記。
* **投資信託の取り扱い**：多くの先で投資信託は「その他の証券」に計上され、その中に外債ファンドが含まれる可能性があるが、**中身は通常非開示**。外債エクスポージャーに含めず `ファンド保有（中身不明）` として Product Familiarity 側で評価。
* 外国証券の前期比減少は **残高変動のみを記録**。売却・償還・為替換算・時価変動の区分は、資料に明記がある場合に限り記載。
* 地銀は **単体** を原則（運用主体＝銀行）。連結しか開示がない項目は `連結` と明記し、単体項目とは比較・合算しない。
* 計数単位：百万円に統一（原資料単位は `原単位` 列に保持）。

### 5-3. 評価保留とデータ充足率

* 各サブ項目の状態：`採点済` / `評価保留（非開示）` / `評価保留（未調査）`。**評価保留は 0 点とせず分母から除外**。
* 出力する指標：
  * `確認済み得点` = Σ(採点済み項目の得点)
  * `確認済み満点` = Σ(採点済み項目の満点)
  * `参考スコア（100換算）` = 確認済み得点 ÷ 確認済み満点 × 100
  * `データ充足率` = 確認済み満点 ÷ 100
  * `VERIFIED比率` = 採点根拠のうち Tier 1 の割合
* ランキングは **参考スコア × 充足率の閾値**（例：充足率 60% 以上のみ本ランキング、未満は「データ不足候補」として別表）で作成し、データの多い先が過大評価・少ない先が過小評価されないようにする。

### 5-4. セグメント（Type A〜E）判定ルール（複数該当可）

| Type | 判定ルール（初期案） |
| --- | --- |
| A 外債規模大 | 外国証券残高が業態内上位20% または 外国証券／有価証券が業態内上位20% |
| B 外債縮小 | 外国証券残高が直近2期で累計 ▲20% 以上（要因は判定しない。要因の開示があれば別列に記録） |
| C 外債積極化 | 外国証券残高が直近2期で累計 +20% 以上、または拡大方針の明示記述 |
| D 規模大・外債比率低 | 有価証券残高が業態内上位30% かつ 外国証券比率が業態内下位40% |
| E ファンド活用 | D1 または D2 が採点済みで加点あり |

### 5-5. ターゲット抽出

* 優先調査30 → 詳細分析15 → 初期提案10 の順で絞り込み。各段階で件数に満たない場合は **無理に埋めない**。
* 全国偏り防止：上位30の地域分布（9地域区分）と業態分布を Dashboard で可視化し、偏りがある場合は理由（スコア由来か、開示粒度由来か）を注記。
* プロファイル（上位候補）は「事実（出典付）」「推論（根拠と確信度：高/中/低）」「営業仮説」を列・色で分離。
