### 1.2 母集団確定ルール

1. **基準日**：2026-09-30（全銀協速報と同じ月末）を「母集団基準日」とし、それ以降の合併・商号変更は `変更イベント` 列に記録して反映可否を別途判断する。

3. **識別キー**：`金融機関コード`（4桁、文字列で保持）を主キー、`法人番号`（13桁）・`正式名称` を副キー。3 つが揃わない先は `NOT YET CHECKED` のまま母集団に残す（除外しない）。
4. **持株会社**：投資主体は**銀行単体**。持株会社は `持株会社名` `持株会社法人番号` の属性として記録し、行は作らない。有価証券報告書が持株会社単位でしか出ていない場合、連結数値は「連結（持株会社）」として区別し、単体比較には使わない。
5. **合併・商号変更**：2024年4月以降の合併・商号変更・業態変更を `変更イベント` に記録。存続会社のみを母集団に含め、消滅行の過去期データは存続行のコードの下に「合算前」と注記して保持する（前期比計算では注記付きで扱う）。
   - 2026年中に統合予定・統合済みと報じられている案件は Phase 1 で一次資料により個別確認する（本書では個別名を確定扱いしない）。
6. **信金中央金庫**：個別信用金庫とは別の投資主体として 1 行で管理。業態内順位は付けず、単独プロファイルとして分析。

### 5.2 ルーブリック（定性項目の共通形）

| 判定 | 意味 | 配点比率 |

| 明確 | Tier 1 資料に具体的記述（数値・方針・時期のいずれか）がある | 100% |

**財務健全性の点数は「運用に制約が少ない可能性」を示すのみで、投資余力・購入意欲とはみなさない**（プロファイルにもその旨を明記）。

### 5.3 欠損の扱いとスコア表示

- `評価保留` の項目は**0 点にしない**。
- **参考スコア** ＝ 評価済み項目の得点合計 ÷ 評価済み項目の配点合計 × 100
- **データ充足率** ＝ 評価済み項目の配点合計 ÷ 100
- **確認済み得点** ＝ 評価済み項目の得点合計（100 点満点表示、充足率が低いと小さくなる）
- 3 つを常に併記。ランキングは「参考スコア」で行うが、**充足率 40% 未満は「データ不足」として順位付けから分離**（閾値は Config）。
- 閾値 40% の理由：自動計算できる定量項目（A1・A2・C1・C2・C3）の配点合計は 42 点。定性項目が評価保留になりやすい信用金庫でも、定量が揃えば順位対象に入るようにするため。定量だけが揃った先の充足率は最大 42% なので、60% にすると定性情報の少ない先（多くの信金を想定）は順位対象から外れる。架空のテストデータで、定量だけが揃った先の充足率が 42% になることを確認した。
- 定量項目は同一期・同一基準（原則 2026年3月期・単体）で揃った先の間でのみパーセンタイルを計算。揃わない先は評価保留。

### 5.4 重みの見直し手順

1. 全国一次収集後、業態別にサブ項目の分布と充足率を確認。
2. 信金で A3/A4/B 系が大半評価保留になる場合、信金ピアでは定量項目中心の別ウェイト（Config で業態別ウェイト表を持てる設計）を検討。
3. 変更時は変更理由・日付を `Config` の改訂履歴に記録し、旧ウェイトでの順位も残す（再現性）。

### 5.5 セグメント分類（複数該当可、点数とは独立）

| Type | 判定条件（初期案。すべて数式またはチェック列で根拠を表示） |
| --- | --- |
| A 外債保有規模大 | 外国証券残高がピア上位 25% または 外国証券比率がピア上位 25% |
| B 外債縮小 | 外国証券残高が 2 期連続減少、または前期比 −20% 以下（**減少要因は別列に「売却／償還／換算／時価／不明」で記録、不明なら断定しない**） |
| C 外債積極化 | 外国証券残高が前期比 +20% 以上、または A3 方向性＝拡大（明確） |
| D 有価証券大・外債比率低 | 有価証券残高がピア上位 25% かつ 外国証券比率がピア下位 50% |
| E ファンド活用 | D1 が「明確」または「示唆」 |

必須機能との対応：

- **コードによる一意管理**：コードは文字列（先頭ゼロ保持）、Universe に重複検知列。
- **業態別・地域別フィルター**：全主要シートにオートフィルタ＋業態・地域ブロック列。
- **データ基準日表示**：Config の母集団基準日・分析対象期を各シート上部に数式で表示。
- **出典 URL とページ**：縦持ちの各数値行に SourceID・ページ、URL は Source Register から参照。
- **前期比・構成比の自動計算**：Foreign Bond Analysis で同一基準の値のみから計算。
- **未確認データの明示**：抽出式が「未調査」「非開示」「不一致」を文字で返し、条件付き書式で着色。
- **スコア算出根拠**：Target Scoring に各サブ項目の判定・根拠EvidenceID・算出式を並記。
- **ランキング更新**：縦持ちに行を追加すると数式で再計算。
- **営業担当者の追記**：Sales Coverage Input / Sales Action Plan は入力用（公開情報シートとは分離、機密区分列あり）。

### 7.4 現実的な作業量の見立て

- 優先 30／詳細 15／初期提案 10 は、データ不足・適合性の問題がある場合は件数を満たさない。
