# 日本の生命保険会社 貯蓄性商品ラインナップ横断表

銀行窓販・証券窓販を中心とした貯蓄性／資産形成系の生保商品を、指定の切り口で横断比較するための
データセットと、それを閲覧するシングルページのビューアです。

- `data/products.json` — 正本データ（これだけを編集する）
- `src/page.html` — ビューアのテンプレート（`__DATA__` にデータが差し込まれる）
- `build.mjs` — データをテンプレートに inline して `index.html` を生成
- `index.html` — 生成物。単体で開ける

```sh
node build.mjs     # data/products.json + src/page.html -> index.html
```

## 収録の切り口

ご指定の 7 つの軸をそのままフィールドに対応させています。

| ご指定の切り口 | フィールド |
| --- | --- |
| 販売チャネル・取り扱い会社 | `channels`（銀行窓販／証券窓販／保険ショップ・乗合代理店／営業職員・専属／ネット・直販）、`distributors`（具体的な銀行・証券会社名） |
| 商品類型 | `categories`（ご指定の 14 類型。複数該当を許容する配列） |
| 商品概要（2-3 行） | `summary` |
| 各社でのペットネーム | `petNames`（配列。世代違い・販売会社別の販売名称・別名を併記） |
| 対象年齢 | `purposes`（介護／老後／生前贈与／相続／長期積立／資産運用／取り崩し）と `ageRange`（契約可能年齢） |
| 裏側の証券会社 | `counterparty`（`present` / `name` / `role` / `index` / `note`） |
| 最新の料率 | `rate`（`value` / `asOf` / `url` / `note`） |

補助フィールド：`insurer`・`group`・`officialName`（正式名称）・`payment`・`currencies`・
`indexLinked`・`confidence`・`sources`。

## 商品類型（`taxonomies.categories`）

ご指定の 14 類型をそのまま ID 化しています。1 商品が複数類型に該当する場合（円建プランと外貨建
プランを持つ一時払終身など）は配列に複数入り、一覧では各類型のグループに現れます。

一時払・定額：`gaika-shushin` / `gaika-nenkin` / `gaika-leva` / `en-shushin` / `en-nenkin` / `en-leva`
指数連動：`shisu-nenkin`
変額：`ichiji-en-gmab` / `en-2kai-gmab` / `ichiji-hengaku-db`
平準払：`hj-en-nenkin` / `hj-gaika` / `hj-en-hengaku-fia` / `hj-gaika-hengaku`

類型の割り当ては、一次資料の正式名称と仕組み記載に基づく本ツール側の分類です。各社の公式な商品
分類とは一致しない場合があります。

## 「裏側の証券会社」について

ご指摘の T&D フィナンシャル生命「セキュアフライト」＝ソシエテ・ジェネラル（SG）と同型のスキーム
を、公表情報から特定できた範囲で `counterparty` に収録しています。現時点で特定できたのは次の型です。

- **戦略連動債型** — 特別勘定が投資銀行の発行する戦略連動債（を組み入れた投資信託）で運用される。
  例：セキュアフライト／SG。
- **カスタム指数型** — 投資銀行が算出・提供するマルチアセット指数を参照指数に据える。
  例：住友生命 たのしみグローバルⅢ 指数連動プラン／SGI FIA マルチ・アセット指数（SG）、
  第一フロンティア生命 プレミアレシーブ2 指数プラン／BNP パリバ米国投資戦略指数。
- **販売証券会社が指数設計に関与する型** — 販売会社が同時に指数の設計・リターン供給の当事者になる。
  例：ニッセイ・ウェルス生命 賢者の終身保険／SMBC 日興証券（設計・リターン供給）＋
  シティグループ・グローバル・マーケッツ・リミテッド（CGML、指数管理者）。
- **汎用市場指数型** — S&P 500 等を直接参照し、上限率（キャップ）でコストを吸収する。
  例：PGF 生命 米国ドル建インデックス年金 PGF。
- **グループ内運用会社型** — 外部投資銀行ではなくグループの運用会社が指数を担う。
  例：第一生命 ステップジャンプ／バーテックス・インベストメント・ソリューションズ。

## 料率の扱い

積立利率・予定利率は各社とも原則として毎月 2 回（1 日・16 日）改定され、通貨・契約年齢・プラン・
高額契約の別で異なります。確定値をデータに固定すると即座に陳腐化するため、`rate` は
**「水準・決まり方・公式の確認先 URL」を保持する設計**とし、ビューアから各社の公式料率ページへ
直接飛べるようにしています。個別に判明した水準は `rate.value` に記載しています。

参考となる横並び水準（2026 年 7 月 16〜31 日契約分、8 社 53 件の調査）：円建 1.95〜3.90%、
米ドル建 3.34〜5.85%。

## データの限界

1. 本データを編纂したセッションの実行環境では、外部サイトへの直接アクセス（HTTP フェッチ）が
   ネットワークポリシーで遮断されていたため、各社サイトの原文ではなく検索エンジン経由の抽出結果に
   基づいています。**数値・名称は必ず `sources` の一次 URL で確認してください。**
2. `confidence: "needs-check"` のレコードは、商品名・引受会社・大分類までは確認できたものの、
   細目（年齢・チャネル・料率・仲介証券会社等）が未確認であることを示します。
3. 商品の改定・新旧世代の切替が頻繁な分野です。提案・比較に用いる前に現行スペックの確認が必要です。

## 追加・更新のしかた

`data/products.json` の `products` 配列に 1 オブジェクト追加し、`node build.mjs` を実行するだけです。
`id` は一意、`categories` / `channels` / `purposes` は `taxonomies` の ID のみを使います。
ビルドスクリプトは JSON をパースしてから差し込むため、壊れた JSON はビルド時に落ちます。
